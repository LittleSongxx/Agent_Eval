### ✅ P3：datetime.utcnow() 废弃

**问题**: 使用 `datetime.utcnow()` 在 Python 3.12+ 废弃，推荐使用时区感知写法。

**修复内容**:
1. ✅ 导入 `UTC` 时区
2. ✅ 替换 `datetime.utcnow()` 为 `datetime.now(UTC)`

**修复前**:
```python
from datetime import datetime, timedelta
now = datetime.utcnow()  # ❌ Python 3.12+ 废弃
```

**修复后**:
```python
from datetime import datetime, timedelta, UTC
now = datetime.now(UTC)  # ✅ 时区感知写法
```
