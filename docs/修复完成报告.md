### ✅ P3：datetime.utcnow() 废弃 API（已修复）

**问题**: 使用 `datetime.utcnow()` 在 Python 3.12+ 废弃

**修复位置**:
- `backend/app/seed.py:1049`

**修复前**:
```python
from datetime import datetime, timedelta
now = datetime.utcnow()  # ❌ 废弃写法
```

**修复后**:
```python
from datetime import datetime, timedelta, UTC
now = datetime.now(UTC)  # ✅ 时区感知写法
```

**验证结果**:
```
✓ 测试全部通过: 235 passed
✓ DeprecationWarning: 从 3 次降至 0 次（seed 相关）
```
