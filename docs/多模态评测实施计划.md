## 📋 实施范围

### ✅ 要做的功能

1. **图像OCR评测**
   - 评测AI对图像中文字的识别准确率
   - 适用场景：文档识别、票据解析、表格提取

2. **图文匹配度评测**
   - 评测AI生成的描述与图像内容的一致性
   - 适用场景：图像描述生成、图文检索

3. **视觉问答评测**
   - 评测AI对图像内容的理解和推理能力
   - 适用场景：视觉问答系统、图像理解

### ❌ 不做的功能（避免过度复杂）

- 视频评测（时序建模复杂）
- 图像生成评测（需要FID等专业指标）
- 跨模态检索（需要额外Embedding模型）
- 图像相似度（需要感知哈希或特征提取）


## 🔧 实现细节

### 1. 图像OCR评测

**评测指标**：
- 字符级准确率（Character Accuracy）
- 词级准确率（Word Accuracy）
- 编辑距离（Levenshtein Distance）

**评测流程**：
```python
1. 输入：图像 + 标准答案文本
2. 调用qwen-vl-plus OCR识别
3. 计算识别结果与标准答案的相似度
4. 返回准确率 + 错误分析
```

**示例**：
```json
{
  "image_url": "https://example.com/invoice.jpg",
  "ground_truth": "发票号码: 12345678",
  "predicted": "发票号码: 12345678",
  "metrics": {
    "char_accuracy": 1.0,
    "word_accuracy": 1.0,
    "edit_distance": 0
  }
}
```

---

### 2. 图文匹配度评测

**评测维度**：
- 内容一致性（Content Consistency）
- 细节准确性（Detail Accuracy）
- 完整性（Completeness）

**评测流程**：
```python
1. 输入：图像 + AI生成的描述
2. qwen-vl-plus理解图像真实内容
3. 对比生成描述与真实内容
4. 从3个维度打分（1-5分）
5. 返回综合得分 + 详细理由
```

**Prompt设计**：
```
你是一个图文匹配度评测专家。

图像内容：[VL模型识别的内容]
AI生成描述：{generated_description}

请从以下3个维度评测：
1. 内容一致性：描述是否与图像内容一致（1-5分）
2. 细节准确性：关键细节是否准确（1-5分）
3. 完整性：是否覆盖了重要信息（1-5分）

输出格式：
{
  "content_consistency": <分数>,
  "detail_accuracy": <分数>,
  "completeness": <分数>,
  "overall_score": <平均分>,
  "reasoning": "<详细理由>"
}
```

---

### 3. 视觉问答评测

**评测类型**：
- 事实性问答（Factual QA）
- 推理性问答（Reasoning QA）
- 计数问答（Counting QA）

**评测流程**：
```python
1. 输入：图像 + 问题 + AI答案 + 标准答案
2. qwen-vl-plus独立回答问题（作为参考）
3. 判断AI答案是否正确
4. 分析错误原因（如有）
5. 返回准确率 + 错误类型
```

**示例**：
```json
{
  "image_url": "https://example.com/traffic.jpg",
  "question": "图中有几辆红色汽车？",
  "ground_truth": "3辆",
  "predicted": "2辆",
  "evaluation": {
    "is_correct": false,
    "reference_answer": "3辆",
    "error_type": "counting_error",
    "reasoning": "AI只识别出2辆，漏掉了右侧被部分遮挡的红色轿车"
  }
}
```

### 3分钟版本

**问题**：
"为什么要加多模态评测？"

**回答**：
"因为现在很多AI应用都涉及图像理解，比如文档OCR、图文生成、视觉问答。传统的文本评测方法无法评估这些场景。

我的方案是：
1. 复用现有的LLM-as-Judge架构
2. 替换评测模型为视觉语言模型（qwen-vl-plus）
3. 设计针对图像场景的评测指标

具体实现了3类评测：
- OCR准确率：评测文字识别效果
- 图文匹配度：评测图像描述生成质量
- 视觉问答：评测图像理解和推理能力

技术挑战主要是：
1. 多模态Prompt设计
2. 评测标准的定义（图像评测主观性强）
3. 成本控制（图像token消耗大）

效果是可以完整评测多模态AI应用的各个环节。"

### 深度追问应对

**Q1: 多模态幻觉怎么评测？**
A: "可以复用已实现的对抗验证机制，让两个VL模型独立评分，分歧大时标记人工复核。另外针对幻觉可以设计专门的评测样本，比如让AI描述图中不存在的物体，检测其是否会幻觉。"

**Q2: 为什么不用CLIP等Embedding模型？**
A: "CLIP适合图文检索和相似度计算，但我的场景是评测AI生成内容的质量，需要detailed reasoning而不只是相似度分数。所以选择了qwen-vl-plus这种视觉语言模型，可以给出详细的评测理由。"

**Q3: 成本会增加多少？**
A: "多模态模型的token消耗确实更大。一张图像大约等效1000-2000个文本token。可以通过以下方式控制成本：
1. 图像压缩和尺寸优化
2. 批量推理（复用图像理解结果）
3. 结果缓存（相同图像不重复处理）
4. 采样评测（不是每个样本都评）

根据实验，成本增加约2-3倍，但可接受。"

**Q4: 如何保证评测的客观性？**
A: "多模态评测确实主观性更强。我的方案：
1. 设计明确的评分维度（如内容一致性、细节准确性）
2. 每个维度有具体的判断标准
3. 使用对抗验证（两个模型独立评分）
4. 引入人工复核机制（分歧样本）
5. 追踪一致性指标（Cohen's Kappa）

这样可以量化评测的可靠性。"
