# 可视化报告增强

## 实现概述

**目标：** 为评测报告增加可视化图表，提升数据洞察能力和面试展示效果

**完成时间：** 2026-08-17  
**技术栈：** React + Recharts + TypeScript

---

## 新增图表组件

### 1. RadarChart（雷达图）- 多维度对比

**用途：** 对比两个版本的多维度指标表现

**使用场景：**
- 校准前 vs 校准后
- 基线模型 vs 优化模型
- 不同评测任务的指标对比

**示例数据：**
```typescript
const data = [
  { metric: 'faithfulness', baseline: 0.75, optimized: 0.85, fullMark: 1 },
  { metric: 'answer_relevancy', baseline: 0.82, optimized: 0.88, fullMark: 1 },
  { metric: 'context_recall', baseline: 0.68, optimized: 0.73, fullMark: 1 },
  { metric: 'context_precision', baseline: 0.79, optimized: 0.92, fullMark: 1 },
];
```

**可视化效果：**
- 一眼看出哪个维度提升/下降
- 面试时展示"新版本 faithfulness 提升 13%，context_precision 提升 16%"

---

### 2. ScatterChart（散点图）- 指标相关性

**用途：** 分析两个指标之间的相关性

**使用场景：**
- faithfulness vs answer_relevancy 相关性
- context_recall vs context_precision 相关性
- 发现"忠实度高的样本，答案相关性也高"

**示例数据：**
```typescript
const data = [
  { x: 0.85, y: 0.82, name: 'Sample 1' },
  { x: 0.73, y: 0.69, name: 'Sample 2' },
  { x: 0.91, y: 0.88, name: 'Sample 3' },
  // ...
];
```

**可视化效果：**
- 显示相关系数（如 0.73）
- 面试时展示"发现 faithfulness 和 answer_relevancy 高度相关（r=0.73）"

---

### 3. TrendLineChart（折线图）- 迭代趋势

**用途：** 展示多次迭代的指标变化趋势

**使用场景：**
- 模型迭代：5 次优化后分数提升
- Prompt 优化：多次调整的效果趋势
- 校准效果：调整阈值后的分数变化

**示例数据：**
```typescript
const data = [
  { iteration: 1, value: 0.65, label: 'v1.0' },
  { iteration: 2, value: 0.71, label: 'v1.1' },
  { iteration: 3, value: 0.75, label: 'v1.2' },
  { iteration: 4, value: 0.79, label: 'v1.3' },
  { iteration: 5, value: 0.82, label: 'v2.0' },
];
```

**可视化效果：**
- 显示总体提升百分比
- 面试时展示"5 次迭代后 weighted_mean 从 0.65 稳步提升到 0.82（+26%）"

---

### 4. BoxPlotChart（箱线图）- 分数分布

**用途：** 展示评分的分布和稳定性

**使用场景：**
- 多次采样分数的分布
- 展示评分稳定性（中位数、四分位距、异常值）
- 对比不同指标的评分波动

**示例数据：**
```typescript
const data = [
  {
    metric: 'faithfulness',
    min: 0.65,
    q1: 0.75,
    median: 0.82,
    q3: 0.88,
    max: 0.95,
  },
  {
    metric: 'answer_relevancy',
    min: 0.70,
    q1: 0.78,
    median: 0.84,
    q3: 0.90,
    max: 0.96,
  },
];
```

**可视化效果：**
- 一眼看出分数集中度
- 面试时展示"faithfulness 中位数 0.82，IQR 仅 0.13，评分非常稳定"

## 技术实现

### 组件架构

```
frontend/src/components/charts/
├── RadarChart.tsx          # 雷达图组件
├── ScatterChart.tsx        # 散点图组件
├── TrendLineChart.tsx      # 折线图组件
├── BoxPlotChart.tsx        # 箱线图组件
└── index.ts                # 统一导出
```

### 技术栈

- **Recharts**：React 图表库，轻量级、易用
- **TypeScript**：类型安全，提升开发体验
- **Tailwind CSS**：快速样式设计

### 核心特性

✅ **响应式设计**：自动适配不同屏幕尺寸  
✅ **交互式**：鼠标悬停显示详细数据  
✅ **可配置**：支持自定义颜色、标签、图例  
✅ **高性能**：基于 SVG 渲染，流畅无卡顿

## 技术细节（面试追问）

**Q: 为什么选择 Recharts？**
> "对比了几个方案：ECharts 功能强大但体积大（500KB+），Chart.js 轻量但 React 集成麻烦，D3.js 灵活但学习曲线陡。Recharts 是专为 React 设计的，组件化、声明式、体积小（50KB），非常适合我们的场景。而且 API 设计优雅，开发效率高。"

**Q: 图表怎么做响应式的？**
> "用 ResponsiveContainer 包裹图表，它会自动监听容器尺寸变化并重新渲染。配合 Tailwind 的响应式类（如 `w-full h-96`），在桌面端显示大图，移动端自动缩小。关键是 SVG 矢量渲染，缩放不失真。"

**Q: 箱线图为什么用 stacked bar？**
> "Recharts 没有内置箱线图组件，所以我用 stacked bar 模拟：下须（min-Q1）、箱体（Q1-Q3）、上须（Q3-max）叠加在一起。虽然不是真正的箱线图，但视觉效果接近，用户能理解分布信息。这展示了我的问题解决能力——没有现成方案时，能创造性地组合现有工具。"
