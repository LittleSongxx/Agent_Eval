# 元评价主实验协议（秋招版）

> 这是下一轮主实验的执行协议，不是已经完成的实验报告。当前状态以 `backend/meta_evaluation_audit.json` 为准；审计为 `blocked` 时，所有结论只能称为 pilot。

## 目标

验证三件事：

1. Judge 分数是否与独立人工判断一致；
2. Agent 轨迹指标是否能识别工具选择、参数、失败恢复和任务完成错误；
3. Citation 指标是否能识别部分错引和严重虚假引用。

## 发布门槛

| 项目 | 最低门槛 | 当前真实值 | 当前状态 |
|---|---:|---:|---|
| Agent 轨迹 | 50 条 | 30 | 阻塞 |
| Agent 错误恢复 gold | 10 条 | 8 | 阻塞 |
| Citation 样本 | 60 条 | 50 | 阻塞 |
| Citation 严重错误 | 10 条 | 0 | 阻塞 |
| 独立标注者 | 2 位 | 1 位 | 阻塞 |
| held-out 样本 | 20 条 | 0 | 阻塞 |
| 稳定 `sample_id` | 全部主实验样本 | 已为现有 80 条 fixture 补齐 | 通过 |

规模扩到 60–100 条是推荐值，不是用重复旧样本凑数。新增样本应覆盖正确、幻觉、截断、无关、引用错位、严重虚假引用、工具错误、恢复成功和恢复失败等分层。

## 标注流程

1. 先生成带稳定 `sample_id` 的候选集，并固定 `dataset_sha256`。
2. 按 `calibration` / `held_out` 划分；held-out 在调 Prompt、阈值和规则前冻结，不能回流调参。
3. 两位标注者独立、盲法标注同一批行；标注表至少包含 `sample_id`、`split`、`annotator`、`label`、`created_at_utc`。
4. 只用双方共同标注、且未看对方答案的行计算人-人 Cohen/Fleiss kappa；仲裁者只解决冲突，不计入人-人一致性。
5. Judge 运行时不得读取人工标签、构造标签字段或仲裁结果；运行后才与人工标签按 `sample_id` 对齐。
6. 在 calibration split 上调阈值或 rubric；held-out split 只做一次最终报告。

## 报告最低内容

- 人-人 kappa（含共同标注行数和 Bootstrap 95% CI）；
- Judge-人 kappa、weighted kappa、Spearman/Pearson；
- confusion matrix、Precision/Recall/F1；
- 按错误类型和 calibration/held-out 分层；
- 校准前后 paired delta 及 95% CI；
- Agent 的 tool selection F1、argument correctness、recovery recall、goal success、step 数、P50/P95 延迟和 token 成本；
- Citation 的 citation precision/recall、unsupported claim rate、nonexistent source rate、major error recall；
- 代码 commit、数据集 SHA256、模型/版本、Prompt digest、随机种子、样本数和标注者数量。

## 当前可执行命令

```bash
cd backend

# 不调用模型，检查当前数据是否达到发布门槛
python -m scripts.meta_evaluation_audit \
  --output meta_evaluation_audit.json --overwrite

# 只生成审计产物，不让 blocked 状态阻止本地文档更新
python -m scripts.meta_evaluation_audit \
  --output meta_evaluation_audit.json --overwrite --allow-blocked

# 新增人工标注和 held-out 数据后，先审计再运行远程 Judge 实验
python -m scripts.agent_trajectory_experiment --dry-run
python -m scripts.citation_accuracy_experiment --dry-run
python -m scripts.generate_evidence_report --overwrite
```

## 不能写进简历的表述

- “Agent 通用能力准确率 X%”；
- “严重引用错误召回率 X%”（没有 major-error gold 时）；
- “kappa 0.8175 已证明泛化”；
- “与 RAGAS 一致所以是真值”。

当前可以准确描述为：平台已实现元评价四层方法、任务口径冻结、双标注数据模型和质量门禁；规模化、双人、样本外的主实验仍待完成。
