## 远程实验的正确口径

### Agent 轨迹

数据集有 30 条轨迹，但错误恢复只有标注子集；报告应至少包含 MAE、Spearman、容差准确率，以及二分类场景的 confusion matrix/F1。轨迹忠实度、工具选择和错误恢复不能简单写成“全体样本平均能力”。

### 引用准确性

数据集有 50 条样本，其中当前标注分布为：完美引用 19、部分错误 31、严重错误 0。因为严重错误样本数为 0，任何“严重错误检测率”都必须写为“不适用”，不能声称 90%+。报告同时给出连续分数误差和“是否存在引用错误”的 precision/recall/F1。

### 并发

并发脚本是独立 Judge 调用的耗时 harness；生产执行器当前的正式保证是行级并发，行内指标仍按顺序执行。并发不会降低 token 成本。没有新的带 provenance 报告前，旧的 `89.45s -> 12.68s` 数字不再作为证据。

## 运行方式

```bash
cd backend
python -m scripts.agent_trajectory_experiment --dry-run
python -m scripts.citation_accuracy_experiment --dry-run
python -m scripts.concurrency_optimization_experiment --dry-run

# 确认 API Key、模型和预算后，再显式运行远程实验：
python -m scripts.agent_trajectory_experiment --output agent_trajectory_report.json
python -m scripts.citation_accuracy_experiment --output citation_accuracy_report.json
python -m scripts.concurrency_optimization_experiment --output concurrency_optimization_report.json
python -m scripts.generate_evidence_report --overwrite
```

实验脚本默认拒绝覆盖已有 JSON；如确实要重跑并替换结果，必须显式追加 `--overwrite`，并保留 Git 提交、数据集 SHA256、模型、命令和生成时间。
