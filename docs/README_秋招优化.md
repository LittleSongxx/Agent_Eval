## ⚡ 快速面试准备（10分钟）

### 1. 背诵30秒电梯演讲

```
我设计了一个对抗验证评测系统，用两个不同LLM形成Judge Panel。

工作流程是三轮对话：
1. Primary Judge（qwen-plus）给初评
2. Adversary Judge（gpt-4o）主动找反例质疑
3. Primary Judge基于质疑重新审视，给终评

分歧超过0.3自动标记人工复核，把人力聚焦在真正有争议的样本上。

我还做了Cohen's Kappa一致性检验，发现：
- "幻觉"判断一致性最高（κ=0.82）→ 可信任单Judge
- "相关性"判断最不一致（κ=0.61）→ 必须对抗验证

成本方面，只对边界样本（20%）启用对抗验证，
总成本只增加40%而不是4倍，这是典型的成本-质量工程权衡。
```

### 2. 记住核心数据

- **代码量**：430行核心 + 350行测试
- **测试覆盖**：7个用例，100%通过
- **成本增加**：边界样本策略仅+40%（vs全量+400%）
- **可靠性提升**：30%误判率下降（估算）
- **一致性**：幻觉κ=0.82，相关性κ=0.61
- **分歧阈值**：0.3（超过标记人工复核）

### 3. 准备3个追问

**Q1: 为什么不直接用更强的模型？**
→ 成本、可靠性、可解释性三维权衡

**Q2: Cohen's Kappa怎么算？**
→ κ = (p_o - p_e) / (1 - p_e)，去除随机因素的一致性

**Q3: 遇到什么技术难点？**
→ Prompt设计迭代、阈值选择实验、成本控制
